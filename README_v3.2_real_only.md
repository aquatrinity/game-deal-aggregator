# 🎮 Game Deal Aggregator (v3.2 - Real Only)

This version guarantees **100% real data only** — no placeholder, mock, or fallback results.

---

## ✅ Sources

- 🛒 **CheapShark API** – Steam, GOG, and store deals
- 🧲 **1337x.to** – Real torrent listings
- 🎁 **FitGirl Repacks** – Clean and popular repack blog

---

## 🔥 What's Special in v3.2

- ❌ Removed all sample/fake/placeholder data
- ✅ Only real results from live scrapers and APIs
- 🧠 Smart cache using SQLite
- 🔍 Game results include: title, price, source, link, image, description
- 🧭 Web UI via Streamlit + CLI optional

---

## 🛠 Tech Stack

- Python 3.12+
- Streamlit (UI)
- BeautifulSoup (scraping)
- Requests (API calls)
- SQLite (cache)

---

